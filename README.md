# Laboratoriya — virtual laboratoriya (7–11-sinflar)

Brauzerda ishlaydigan 3D o'quv o'yini: kimyo, biologiya, anatomiya, shifokor xonasi va «Wow tajribalar».
Kompyuter, sensorli ekran va VR (WebXR) rejimlari bitta sahifada.

**Ochish:** https://innovatorone.github.io/Labalatory-game/

## Uchinchi tomon materiallari
- 3D dvigatel: [Babylon.js](https://www.babylonjs.com/) (Apache-2.0), CDN orqali yuklanadi.
- Odam tanasi modeli: [MakeHuman](http://www.makehumancommunity.org/) bazaviy modeli va skeleti — **CC0**.
- Ichki a'zolar modellari: **BodyParts3D**, © The Database Center for Life Science, **CC BY-SA 2.1 Japan**
  (https://lifesciencedb.jp/bp3d/). O'zgartirilgan (soddalashtirilgan va joylashtirilgan) nusxalari shu litsenziyada tarqatiladi.

Tibbiy va kimyoviy mazmun prototip uchun; haqiqiy darsda foydalanishdan oldin o'qituvchilar tomonidan tekshirilishi kerak.
